## 编号规则（全局唯一，不许跳号，不许复用）

| 前缀 | 含义 | 编号格式 | 用途 |
|---|---|---|---|
| REG | 开工登记 | REG-{序号} 递增 | 任何新冒出来的任务/想法 |
| IMP | 影响圈 | IMP-{序号} 递增 | 动手改文件前登记 |
| DC | 对话卡 | DC-{YYYYMMDD}-{序号} 日期+序号 | 对话收尾 |
| RCA | 根因分析 | RCA-{序号} 递增 | 出 bug 后 |
| RT | 回归测试 | RT-{序号} 递增 | RCA 产出的测试用例 |
| FI | 失败注入 | FI-{序号} 递增 | 推演时的失败轨道 |
| GAP | 缺口回流 | GAP-{序号} 递增 | 推演时发现的未知点 |
| HDL | 恢复包 | HDL-{序号} 递增 | 跨会话接力 |
| UPG | 增量单 | UPG-{序号} 递增 | 版本升级 |
| BLIND | 盲查标记 | BLIND-{序号} 递增 | 竞品调研样本不足 |

**编号递增规则**：
- 先查现有台账文件里的最大编号
- 新编号 = 最大 + 1
- DC 卡特别注意：每天重新从 1 开始，但日期换了
- 不许跳号、不许复用、不许改历史编号

## 三个自动触发点（强制，主 Agent 必须调）

```
触发点 1：开工 → 登记 REG-xx
时机：任何新任务开始的第一分钟
内容：
  → 本次任务要干什么
  → 为什么干（动机）
  → 边界在哪（不干什么）
  → 负责人（默认 AI，用户指定写用户）
  → 到期日（默认本次会话）

触发点 2：动手前 → 登记 IMP-xx
时机：第一次 edit / write 文件前
内容：
  → 谁会用到这次改动（下游消费者）
  → 改动依赖哪些模块（上游依赖）
  → 改完哪些东西会变
  → 是否跨界（跨文件 / 跨模块 / 跨层）
  → 回滚点在哪（git commit 状态 / 配置备份）

触发点 3：收尾 → 登记 DC-xx
时机：对话即将结束时
内容：
  → 这次对话干了啥（一句话）
  → 改了哪些文件（完整路径列表）
  → 跑了哪些命令（输出摘要）
  → 哪些尝试没走通（必须记录！）
  → 产出/遗留问题
```

## 台账四件套模板

### 四件套 1：REG-xx（开工登记）

```
### REG-{序号} — {YYYY-MM-DD HH:mm}
- 任务：{这次要干什么}
- 动机：{为什么干}
- 边界：{不干什么}
- 负责人：AI / {用户名}
- 到期：本次会话 / {日期}
- 关联：IMP-xx / RCA-xx（如果有）
```

### 四件套 2：IMP-xx（影响圈）

```
### IMP-{序号} — {YYYY-MM-DD HH:mm}
- 改动目标：{改什么}
- 上游依赖：{依赖哪些模块/文件}
- 下游影响：{谁会用到这次改动}
- 跨界：是（跨文件/跨模块/跨层）/ 否
- 回滚点：{git commit hash / 配置备份路径}
- 登记时点：动手前
```

### 四件套 3：DC-xx（对话卡）

```
### DC-{YYYYMMDD}-{序号} — {YYYY-MM-DD HH:mm}
- 对话主题：{一句话概括}
- 改文件清单：
  - {文件路径 1} — {改了什么}
  - {文件路径 2} — ...
- 跑命令摘要：
  - {命令} → {成功/失败 + 关键输出}
- 未走通的尝试（必须记录！）：
  - {尝试 1} → {为什么没走通}
- 产出：{REG-xx / IMP-xx / RCA-xx / RT-xx 等编号}
- 遗留问题：{还没解决的}
```

### 四件套 4：RCA-xx / RT-xx 等其他类型

按各自 agent 的输出格式登记，但必须编号 + 日期 + 摘要。

## 台账文件位置

| 文件 | 位置 | 内容 |
|---|---|---|
| 工作流水.md | 工作目录根 | 每次对话自动追加 DC-xx |
| CHANGELOG.md | 项目根 | 升级台账 UPG-xx |
| 独立台账 | 可按类型分文件 | REG / IMP / RCA 等 |

**归档规则**：
- 每次登记先查现有台账，遇到同类问题 → 合并到已有条目
- 不同类型 → 新建条目
- 跨 AI 会话接力时，必须先读历史台账

## 必查表

| 场景 | 必须问 |
|---|---|
| 开始新任务 | REG-xx 登记了吗？ |
| 改文件前 | IMP-xx 登记了吗？回滚点在哪？ |
| 对话收尾 | DC-xx 写了吗？未走通的尝试记录了吗？ |
| 查编号 | 这个编号最大是几？新编号是多少？ |
| 跨会话接力 | 上次 DC-xx 是哪天的？遗留问题是什么？ |
