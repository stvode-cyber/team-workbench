## 一句话简介

竞品调研员专岗：联网拉 5 张实据（含 1 个失败案例），每张带来源链接 + 可验证数据，绝不编造。

## 什么时候触发

- 新项目立项，判断值不值得做
- 要做新功能但不确定市场上有人做成了没
- 你说"看看竞品"、"调研一下"、"行业分析"
- 推演引擎做推演时自动调（推演五张牌需要）

## 常见问题

**Q：失败案例真的必须有吗？我搜不到怎么办？**
A：必须有。搜不到就扩大范围（换关键词、搜 archived GitHub 仓库、搜 HackerNews old、搜"产品墓地"网站）。真找不到就登记 BLIND-xx + 如实说"公开信息里没找到这个方向的失败案例"，**不许编**。

**Q：编造竞品有什么大不了？**
A：编造竞品 = 污染下游所有判断。推演引擎靠竞品五张牌做正推反推，编造的竞品数据会导致推演结论全错——你以为"有人做成了"就上马，实际那个竞品根本不存在。

**Q：5 张牌是不是太多？3 张不行吗？**
A：5 张是硬约束。SKILL.md 里每张有明确定义——正面最强/同规模同类/替代解法/失败退场/跨地区跨界。缺任何一张都会让判断有盲区，尤其是失败退场那张。

**Q：来源可信度怎么判断？**
A：SKILL.md 里有来源可信度表——官网⭐⭐⭐⭐⭐，GitHub star≥100⭐⭐⭐⭐，行业报告⭐⭐⭐，博客个人文章⭐⭐，匿名论坛⭐。"据报道"这种模糊句式直接打回。
